口說 · 跟讀

聽示範，大聲唸出來

先聽標準發音，再按麥克風唸一次，系統會標出唸對與漏掉的字。

按示範聽一次，再按黑色麥克風開始唸。
  • 注意句尾的子音（-s、-ed、-t），台灣學習者最常漏掉。
  • 先慢速跟讀三次，再用正常速度唸。
  • 發音由瀏覽器內建語音播放，不同裝置的聲音會略有差異。
單字卡與進度只存在這台裝置的瀏覽器中。文字辨識：Tesseract.js（在手機上執行）· 字典：Free Dictionary API · 中文翻譯：MyMemory。
